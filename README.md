## 🧠 Featured AI Architecture — NovaCart Intelligence

### Hybrid Retrieval for Business Intelligence

The proposed system combines structured analytics and semantic retrieval to help users investigate business questions using both quantitative metrics and relevant customer feedback.

### Query Processing Modes

| Mode | Data Source | Purpose |
|---|---|---|
| 📊 SQL | DuckDB | Analyze structured business metrics |
| 🔎 Semantic Search | Qdrant | Retrieve relevant customer feedback |
| 🧠 Hybrid | DuckDB + Qdrant | Combine metrics with contextual evidence |

### How It Works

1. **Understand the question:** Determine whether the request needs SQL, semantic search, or both.
2. **Extract filters:** Identify relevant time periods, regions, products, and business segments.
3. **Query structured data:** Retrieve metrics using SQL.
4. **Retrieve contextual evidence:** Search customer feedback using semantic similarity and metadata filters.
5. **Synthesize findings:** Combine the retrieved evidence into a concise answer.
6. **Support verification:** Present relevant source records and query details where available.

### Example Use Case

**Business question:** Why did enterprise revenue decline in a particular region?

A hybrid workflow could compare revenue across reporting periods, identify changes in account activity, and retrieve customer feedback related to the affected accounts.

The resulting analysis should distinguish verified metrics from possible explanations rather than treating correlation as proof of causation.

**Architecture**

`Business Question → Intent Router → SQL + Vector Retrieval → Evidence Synthesis → Answer`

**Engineering Concepts**

`Text-to-SQL` `Embeddings` `Vector Search` `RAG` `Metadata Filtering` `LLMs`

*Note: NovaCart is presented as a project concept. Example business results should only be published as actual results after validation against real data.*
